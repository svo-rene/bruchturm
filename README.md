# Bruchturm

Ein Deckbau-Lernspiel zu rationalen Zahlen (Brüche, Dezimalzahlen, Prozent, negative Zahlen).

- Gegner zeigen ihre nächste Aktion als Rechenausdruck – ausrechnen und passend blocken.
- 🎯 Kern: Angriffe so kombinieren, dass die Summe genau die Kern-Zahl ergibt.
- Rechenkarten und Rätselräume mit typischen Fehlvorstellungen als Ablenker und Lösungsweg.
- Drei Stufen: nur Brüche · + Dezimal & Prozent · + negative Zahlen.

Spielen: `index.html` im Browser öffnen – keine Installation nötig.
